# のびーる（Nobiiru）

首をのばして、空のたべものを食べるだけ。最もシュールな一本指ゲーム。

## 遊び方
- **画面を押しっぱなし**で、生き物「ムチオ」の首がにゅ〜っとのびます。離すと戻る。
- 🟢 **みどりのわ** のもの（🍡🍙🍣🌙🛸👁️）＝ たべる！ 連続で食べるとコンボ倍率アップ。
- 🔴 **あかい点線・ブルブル** のもの（⚡🌶️💀🧦🪨）＝ ダメ！ 食べると きぶん🫧 が減り、3つで おわり。
- スコアが伸びると、世界がだんだんシュールに崩壊していきます。

## 技術
- 単一 `index.html` で完結（画像・外部依存なし・オフライン動作）
- Canvas 2D 描画 + WebAudio で効果音を自動生成
- スマホのブラウザ最適化（縦持ち・タッチ操作）

ブラウザで `index.html` を開くだけで遊べます。
