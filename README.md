# ヘンゲー横丁

しょうもない・シュールな一本指ゲームの寄せ集め。野田ゲー的に「わざと雑・手描き・ケバい」。

`index.html` がトップ（ハブ）。カードをタップすると各ゲームへ飛ぶ。

## 入っているゲーム

- **のびーる**（`nobiiru.html`）— 首をのばして空のたべものを食べる。最もシュールな一本指ゲーム。
- **ツッコミ**（`tsukkomi.html`）— ヘンなやつが出てくる。リズムに合わせて「ばしっ」とツッコむ。
- **ペタ拳**（`kakutou.html` ＋ `kakutou/`）— すきな画像を貼ってキャラにし、1対1でなぐりあう格闘ゲーム。下に詳細。

## 設計（増やし方）

- 各ゲームは **単一HTMLで完結**（画像・外部依存なし・オフライン動作）。
- 見た目は **Canvas 2D ＋ 絵文字**。音は **WebAudio で自動生成**（音源ファイル無し）。
- スマホ縦持ち・タッチ前提。
- **ゲームを増やすとき**は次の2ステップだけ:
  1. 新しい `xxx.html` を1つ足す（のびーる／ツッコミを雛形にできる）。
  2. `index.html` の `GAMES` 配列に1行足す（`{href, emoji, name, tag, color, ready}`）。

## リズムゲームの時間管理（ツッコミ）

野田ゲーでも「拍に乗る気持ちよさ」の芯は妥協しない。発音時刻を `setTimeout` ではなく
`AudioContext.currentTime` に予約し、ヘンなやつの位置も同じ音声時計から引く。
だから「拍で中央に来る→拍でタップ」が音とズレない。

## 遊び方

ブラウザで `index.html` を開くだけ。同じWi-FiのスマホからPCのIPで開けば実機で遊べる。

## ペタ拳（画像で格闘）

横丁の中で唯一「一本指」でなく、キーボード/ゲームパッド/画面ボタンで遊ぶ。規模が大きいので
`kakutou/` に役割ごとのファイルを分けた（どれも他を知らずに差し替えられる）。

| ファイル | 役割 |
|---|---|
| `pixel.js` | ドット描画の土台。低解像度レイヤー＋ふちを0/255に切る crisp()、ドット文字 |
| `store.js` | 保存(IndexedDB。使えなければ localStorage)。キャラ・設定 |
| `cutout.js` | 背景けし(おまかせ/まる/そのまま＋ブラシ)・画像しんだん・ステッカー化。外部AI不要 |
| `chars.js` | キャラのデータ形・タイプ→強さ・みほんキャラ・画像→戦闘用素材。ポーズ画像(poses)の引き当て |
| `fighter.js` | 技表(フレーム)・状態遷移・物理。描画は rig(関節位置)→ドットの体＋高解像度の写真。見せ方3種 |
| `input.js` | キーボード/タッチ/ゲームパッドを同じ {l,r,u,d,a,b,c} にそろえる |
| `ai.js` | CPU(人と同じ入力を返すだけ・3段階) |
| `stage.js` | ドット絵ステージ3種(廃ビル/シャッター街/銭湯)。STAGES に1つ足せば増える |
| `battle.js` | VS画面→登場→対戦→K.O.→勝利画面、当たり判定、演出(ヒット星・衝撃波・フラッシュ・残像・カメラ寄り)、アーケードHUD、音 |
| `app.js` | 画面の流れとキャラ管理/編集UI |

- **バランスの芯**: やられ判定は画像の形に関係なく全員同じ箱(画像の表示範囲と判定は別)。能力値は 体力/攻撃力/防御力/移動速度 の4つ×1〜5で **合計12ポイント固定**。1段階の差は±6〜8%(式は chars.js の mods)。
- **ダメージ**: 技の基本値 × 攻撃力倍率 × 相手の防御力倍率 × コンボ補正。ガード中は15%(通常技の削りではKOしない)。必殺(飛び道具)はクールダウンあり。
- **反転**: キャラごとに「反転しない(文字・ロゴ向け)」か「相手の方へ反転(元画像の向きを指定)」。振り向きは紙がめくれるアニメ。
- **固め防止**: ガード耐久(ガードし続けると割れる)。浮いた相手は追撃不可(永久コンボ防止)。
- **将来のポーズ差し替え**: キャラの `poses:{attack,hit,ko,win}` に画像を入れれば、その状態でその画像に変わる(UI未実装・描画側は対応済み)。
- 起動: `ヘンゲー横丁をあそぶ.bat`(= `python serve.py` → http://localhost:8123/index.html)から「ペタ拳」カード。

### 見た目(2026-10-11 アーケード化)

- 90年代アーケードのベルトスクロール風。**世界はドット(低解像度)、ユーザーの写真だけ高解像度**で重ねる＝「写真の顔がドットの体に乗ってる」ズレが笑いどころ。
- 見せ方は画像の形で おまかせ判定(編集画面で変更可): **顔ハメ**(正方形に近い/まる切り→写真を頭に、服4種のドットの体) / **胴体**(横長〜やや縦長→写真が胴体、棒の手足) / **まるごと**(とても縦長→写真そのものが体、手袋が宙に浮きバネで飛ぶ)。縦横比は一切いじらない。
- 文字は Google Fonts の DotGothic16 / Press Start 2P。オフラインだと代わりのフォントになる(キャンバス内は低解像度描画なのでドット感は残る)。

### 格闘システム(2026-10-11 本格化)

- **操作**: A/D 移動(相手の方へ=前進/反対=後退)・W ジャンプ・**S しゃがみ**・J 弱・K 強・L 必殺・I 投げ(弱+強同時押しでも可)。**ガード=相手と反対方向を押す**(専用キーなし)。
- **攻撃の段**: 上段(しゃがみで空振り)/中段/下段(しゃがみガードのみ)/空中技(立ちガードのみ)。技表は `fighter.js` の `MOVES`(発生・持続・硬直・ダメージ・削り割合・ガード硬直・被弾硬直・ノックバック・判定の箱=届く距離・キャンセル先)。
- **三すくみ**: 打撃 > 投げの出かかり / 投げ > ガード / ガード > 打撃。投げは つかまれて10F以内に投げボタンで「投げぬけ」。硬直明け6Fは投げられない。
- **コンボ**: キャンセル(弱は2回まで)でつなぐ。補正 1,1,0.85,0.72…。4段目以降は のけぞりが短くなり必ず途切れる。終わると「n HITS / ダメージ」表示。
- **ダウン**: 足払い・空中ヒット・投げ・超必殺でダウン → ダウン中は無敵 → 起き上がり(無敵20F)。
- **CPU** (`ai.js`): 反応(技の段に合わせたガード・届く技だけガード・空振りへの踏み込み反撃・対空・投げぬけ・飛び道具よけ)＋作戦(間合い別の重みづけ抽選、ガードを固める相手には投げ、くり返し防止)。レベルで反応速度と確率が変わる。
- **時間**: 更新は1/60秒の固定ステップ、描画は別(リフレッシュレートに関係なく同じ速さ)。キーは押した瞬間をラッチするので短いタップも落ちない。

### テスト

- `node kakutou/tests/run.js`(Node)または `kakutou/tests/tests.html`(ブラウザ)。描画なし(headless)の本物のBattleを台本入力で動かす。
- 38項目: 発生フレーム・持続・射程・ダメージ式・防御力・削り・ガード/被弾硬直・上段/下段/空中技のガード・ノックバック・コンボ(接続/補正/上限/集計/全能力値の組み合わせ)・投げ/投げぬけ・ダウン/起き上がり・クールダウン・ラウンド/タイムアップ/引き分け/試合終了・固定ステップ・先行入力・能力値上限・CPU(接近/ガード/下段ガード/反撃/行動のばらつき/CPU同士の完走)。

### スマホ・起動

- `ヘンゲー横丁をあそぶ.bat` でサーバー起動(起動済みなら そのまま)＋横丁のトップを開く。横丁トップ・ペタ拳タイトルの「スマホで あそぶ」に、同じWi-FiのスマホでひらくURLとQRが出る(serve.py の `/__lan` がPCのIPを返す。100.x は Tailscale)。
- スマホ: 左半分=指を置いた所に出るスティック(ななめ=しゃがみガード可)、右=弱/強/必殺/投(指をすべらせて押し替え・2本指同時押し可)。対戦開始で全画面＋よこ固定を試み、たて向き中は一時停止。重い端末は自動で軽量描画。
- キャラはブラウザごとに保存(PCとスマホは別)。

### 声

- `kakutou/voice.js`。既定は「ペチャクチャ声」(文字→音節→母音ごとのフォルマント音。WebAudioのみ・インストール不要・全端末同じ)。タイトルの「こえ」で ペチャクチャ / よみあげ(端末TTS) / なし を切替(保存される)。
- スマホのダブルタップ拡大は touch-action と対戦画面の touchend/gesture 抑止で止めている(メニューの連打は止めない)。

### VOICEVOX(声)

- PCに VOICEVOX(無料・https://voicevox.hiroshiba.jp/ 、GPUなしPCは CPU版)を入れて起動 → `アナウンス音声をつくる.bat`(= `python kakutou/tools/make_announcer.py [キャラ名]`)で `kakutou/voice/*.wav` と `manifest.json` を作る。ゲームに同梱されるので スマホでも鳴る。
- キャラ編集の「VOICEVOX」で声を選んで保存 → 掛け声・必殺技名(キャラの声)と 名前・勝ち名乗り(アナウンスの声)を作って キャラに保存(`voiceClips`)。serve.py の `/__vv` が PC の VOICEVOX へ中継するので、同じWi-Fiのスマホからも作れる。
- 利用規約により「VOICEVOX:キャラ名」を表示(タイトル下部・編集画面)。こえモード: VOICEVOX / ペチャクチャ / よみあげ / なし。録音が無いセリフはペチャクチャ声。

### スマホ優先UI(2026-10-12)

- 対戦: スマホのたて持ち=上に試合(体力・タイムの帯／ゲージの帯つき、Battle の portrait レイアウト)・下に操作パネル。よこ持ち=全面＋ボタン重ね。向きを変えるとその場で切替(Battle.setLayout)。
- メニュー: 決定ボタンを画面下に固定、タップ領域を大きく、キャラ選択はパネルを小さくして一覧を広く、遊び方/ポーズはタッチ操作の説明。
